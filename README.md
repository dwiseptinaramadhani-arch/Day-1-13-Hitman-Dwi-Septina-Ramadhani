# Day-1-13-Hitman-Dwi-Septina-Ramadhani
Dokumentasi Workshop Day 1

Deskripsi Repository
Repository ini dibuat sebagai dokumentasi kegiatan Workshop Day 1 yang membahas pemanfaatan AI, Prompt Engineering, 
serta penggunaan Git dan GitHub untuk manajemen perubahan dan kolaborasi dalam pengembangan proyek.

Tujuan Repository
Repository ini bertujuan untuk menyimpan catatan, rangkuman materi, dan hasil pembelajaran selama mengikuti workshop,
serta sebagai bukti partisipasi dalam kegiatan Day 1 Project Workshop.

Rangkuman Materi
Pada workshop Day 1, peserta mempelajari cara memanfaatkan AI melalui Prompt Engineering agar dapat menghasilkan jawaban yang lebih tepat dan relevan. Prompt yang baik harus memiliki struktur yang jelas, meliputi Role, Task, Context, dan Format. Selain itu, peserta juga mempelajari Git dan GitHub sebagai alat untuk version control dan kolaborasi dalam pengembangan proyek. Materi mencakup pengenalan repository, commit, branch, pull request, workflow Git, serta beberapa perintah dasar seperti git init, git add, git commit, git push, dan git pull. Workshop juga memperlihatkan bagaimana menghubungkan proyek lokal dengan GitHub dan mengelola perubahan kode secara terstruktur. 

Selain mempelajari Git dan GitHub, workshop juga membahas Prompt Engineering, yaitu cara memberikan instruksi kepada AI agar menghasilkan jawaban yang lebih sesuai dengan kebutuhan pengguna. Struktur prompt yang baik terdiri dari Role (peran AI), Task (tugas yang diberikan), Context (latar belakang atau informasi pendukung), dan Format (bentuk output yang diinginkan). Dengan menggunakan struktur tersebut, hasil yang diberikan AI menjadi lebih jelas, relevan, dan akurat. 
Workshop juga menjelaskan perbedaan antara Git dan GitHub. Git adalah sistem version control yang digunakan untuk melacak dan mengelola perubahan pada file atau kode program secara lokal. Sedangkan GitHub merupakan platform berbasis web yang digunakan untuk menyimpan repository Git secara online serta mendukung kolaborasi antar pengguna dalam mengembangkan proyek secara bersama-sama.

Poin-Poin Penting yang Dipelajari
1. Prompt yang spesifik dan memiliki konteks yang jelas akan menghasilkan output AI yang lebih baik
2. Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format.
3. Git adalah sistem version control yang digunakan untuk melacak perubahan pada file dan kode program.
4. GitHub adalah platform berbasis web untuk menyimpan repository Git dan mendukung kolaborasi tim.
5. Workflow Git terdiri dari Working Directory, Staging Area, dan Repository.
6. Beberapa perintah penting Git meliputi git init, git add, git commit, git push, dan git pull.
7. GitHub memudahkan penyimpanan proyek, berbagi kode, serta kerja sama antar developer.

Saya juga mendapatkan pengetahuan baru mengenai pentingnya Prompt Engineering untuk memperoleh hasil yang lebih maksimal saat menggunakan AI.
